# Project delivery

After completing and verifying coding changes, commit appropriate project files
with a meaningful message and push when permissions and authentication allow.
The user confirmed this destination:
https://github.com/DemoiselleAnn/IoT_Based_Water_Quality_Monitoring_with_Fish_Recommendation
Use branch `main` unless the user directs otherwise. Verify the remote before
every push. Never force-push or overwrite remote changes. Check for secrets before
staging; never commit real credentials or environment files. Report the repository
URL, branch, and commit hash after a successful push. Authentication is currently
a development mock; the example password in the source is not a production secret.
